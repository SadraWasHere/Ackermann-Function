Introduction & Tutorial
=======================
This is an ackermann function, saved in a python module. This how you can use if you want:
1. Copy ```ackermann.py``` to a directory that you want to.
2. In your python file write:
```from ackermann import ack```

Usage
=====
The ```ack()``` function takes 2 arguments: 
1. The first argument as your "m", the first parameter.
2. the second one as your "n", the second parameter.
Note: Be careful with large values of ```m``` and ```n```! This function grows extremely fast and may easily hit Python's recursion limit.
